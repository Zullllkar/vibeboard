0.9 这一代

0.9.0 是第一个 Windows 桌面版。最新一版是 0.9.4。再往前的 0.8.6 还是画布稿，没有安装包。

查看 0.9.4 的安装说明

0.9.4

2026-10-09
  • 页眉可以在亮色和暗色之间切换，选择记在本机。
  • 画布上的那句起点会留下，关掉窗口再打开还在。
  • 起点最多 80 个字。不到四个字不会放到画布上。
  • 交接清单的第一行跟着这句起点走，刷新之后仍是同一句。

0.9.2

2026-09-18
  • 画布滚动时，散开的句子收到一块页面。
  • 页面再连到旁边的约束，选区跟着当前这一块。
  • 图层按感觉、画板、约束切换。滚动时，当前这一层会亮起来。
  • 检查器显示这一块的名字，以及 X、Y、W、H。

0.9.0

2026-08-06
  • 第一个 Windows 桌面版。不需要账号，画布留在本机。
  • 窗口里是图层、画布和检查器。
  • 一个 session：写下感觉，收成设计，把约束交给 Cursor。
  • 个人版同时进行一个 session。买断从这一代开始按一次付款计。

0.8.6

2026-06-21
  • 还不是安装包。画布稿里，句子可以先散开，再收成一块页面。
  • 没有检查器，也没有交给 Cursor 的约束栏。
  • 0.9.0 起才装进 Windows 桌面窗口。
