Vibeboard 0.9.4
Windows 10 64 位 / Windows 11
2026-10-09

这一份是 0.9.4 的安装说明。签名安装包还没挂到公开地址，文件名会是 Vibeboard-Setup-0.9.4.exe。

准备
1. 系统用 Windows 10 64 位，或 Windows 11。没有 macOS，也没有 Linux 安装包。
2. 留一个本地文件夹。画布写在这台电脑上。换电脑时，自己把这个文件夹带走。
3. 不需要账号，也不需要独立显卡。程序不登录，画布不上传。

打开之后
1. 安装包上线后，运行 Vibeboard-Setup-0.9.4.exe。
2. 打开 Vibeboard，看到图层、画布和检查器。
3. 写一句它应该长什么样。这句话是这个 session 的起点。

交接
选中画布上的一块，旁边是交给 Cursor 的约束。
个人版在窗口里阅读这份约束。
买断之后，可以把约束导出成一份本地文件。

版本
个人：一个进行中的 session，¥0。约束在窗口里阅读。
买断：进行中的 session 不限，一次 ¥168，包含 0.9 这一代的更新。约束可导出成一份本地文件。
