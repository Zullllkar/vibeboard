# Vibeboard 视觉规格

参考来源：https://paper.design/ （首页结构与 Fudge 对其实测色值、字重、组件的记录）。这是 Vibeboard 自己的页面，不沿用 Paper 的标志、文案和产品画面。

一句话：纯黑画布上用暖白米白做细字，产品以「画板 + 检查器」的方式出现，深度靠表面明度，不靠渐变和阴影。

## 色板

取自参考站实测色，再换成 OKLch。`--accent` 就是暖白本身：主按钮用它做底，字用近黑。页面上不再加第二种彩色。

| Token | OKLch | 来源 |
| --- | --- | --- |
| `--bg` | `oklch(0% 0 0)` | `#000000` 页面底 |
| `--surface` | `oklch(13.44% 0 89.88)` | `#080808` 抬起的面板 |
| `--fg` | `oklch(94.99% 0.0146 102.46)` | `#F0EFE4` 暖白正文 |
| `--muted` | `oklch(65.34% 0 89.88)` | `#909090` 次级说明 |
| `--border` | `oklch(32.11% 0 89.88)` | `#333333` 分割线 |
| `--accent` | `oklch(94.99% 0.0146 102.46)` | `#F0EFE4` 主按钮填充 |

派生表面（仍在同一套明度里）：

- `--surface-2`: `oklch(27.27% 0 89.88)`（`#272727`，选中与对话框）
- `--border-subtle`: `oklch(28.50% 0 89.88)`（`#2A2A2A`）
- `--inverse`: `oklch(13.44% 0 89.88)`（按钮上的字）
- `--btn-hover`: `oklch(86.99% 0.0146 102.46)`（暖白 L −0.08）
- `--btn-active`: `oklch(82.99% 0.0146 102.46)`（暖白 L −0.12）
- `--danger`: `oklch(82.19% 0.0724 31.48)`（仅错误文案）

`#555555` 在黑底上对比约 2.8:1，只可做非文字的弱边，页面正文不用它。`#909090` 在黑底上约 6.6:1。

## 亮色主题

页眉「亮色 / 暗色」切换，选择记在 `localStorage` 的 `vibeboard-theme`。默认仍是暗色。亮色沿用同一暖色相（102.46），只把明度反过来：纸色底、近黑字，主按钮改为近黑底、纸色字。网格、标尺、发丝边改成低透明度的墨线。画布上的设计稿仍是暖白纸面。

| Token | 亮色 OKLch |
| --- | --- |
| `--bg` | `oklch(96.4% 0.008 102.46)` |
| `--fg` | `oklch(20% 0.014 102.46)` |
| `--muted` | `oklch(39% 0.014 102.46)` |
| `--border` | `oklch(76% 0.014 102.46)` |
| `--accent` | `oklch(20% 0.014 102.46)` |
| `--inverse` | `oklch(96.4% 0.008 102.46)` |

## 字体

参考站实测：

- 展示与短句：Matter，约 360，字距 −0.02em，行高 1
- 长文：Inter
- 标签与坐标：Paper Mono

Matter（Displaay）和 Paper Mono 是商业字体，页面不外链它们的文件。角色对应为：

- 展示：`"Outfit", "Noto Sans SC", sans-serif`（300）
- 正文：`"Inter", "Noto Sans SC", sans-serif`（400）
- 等宽：`"IBM Plex Mono", "Noto Sans SC", ui-monospace, monospace`（400）

中文没有 Matter 的免费对应，标题用 Noto Sans SC 300，正文用 Noto Sans SC 400，拉丁标题走 Outfit，拉丁正文走 Inter。

## 视觉规则

实测自参考站首页结构（2026-10 抓取的页面与样式），不只是色值：

1. 底是纯黑，字是暖白，主按钮是暖白底、近黑字，按钮圆角 4px。悬停把底的明度降约 0.08，字保持近黑。按下 `scale(0.97)`。
2. 大标题很细、左对齐、行高 1、字距 −0.02em，桌面约 56px。第一行暖白，紧接着的两行用次级灰，同一字号。说明 16px、行高 28px，用次级灰。
3. 整页是一张设计画布：120px 网格铺满，左边和底边有标尺，刻度跟着滚动走。区块交接处用 12px 的套准方块。
4. 主视觉是一块浮起的产品窗口，比例约 1516×826，圆角 12px，发丝描边加一条很长、很淡的阴影。窗口里是可交互的工具界面，不是贴一张概念图。
5. 等宽只给步骤、坐标、尺寸和眉题。层次靠明度差。不用渐变洗底、彩色强调和投影卡片。
6. 下方内容落在发丝线画成的画板格子里。进入视口时，标题用 0.8s 从模糊 5px、下移 8px 淡入。
